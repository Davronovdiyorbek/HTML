Text formatting tags

Use text elements to create hierarchy, paragraphs, emphasis, and meaningful inline annotations

<h1–h6>

Definition

Headings define the hierarchy of page sections.

Attributes

AttributeRole
idUnique identifier.
classCSS class names.
titleAdvisory information.

Example (code)

<h2>A section heading</h2>

Example (result)

Browser preview

A section heading

<p>

Definition

The paragraph tag groups a block of text into a paragraph.

Attributes

AttributeRole
idUnique identifier.
classCSS class names.
langLanguage of the content.

Example (code)

<p>HTML gives content a clear structure.</p>

Example (result)

Browser preview

HTML gives content a clear structure.

<strong, em>

Definition

These tags mark important text and emphasized text.

Attributes

AttributeRole
idUnique identifier.
classCSS class names.
titleAdditional information.

Example (code)

<p><strong>Important:</strong> practice <em>every day</em>.</p>

Browser preview
