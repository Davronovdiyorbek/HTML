# HTML Review Guide

This is my beginner HTML project for learning HTML tags.

## How to open it
1. Extract this ZIP file.
2. Open `index.html` in a browser.
3. Use the menu to visit the other pages.

## Files
- `index.html` — home page
- `text.html` — text tags
- `links.html` — links
- `lists.html` — lists
- `tables.html` — tables
- `forms.html` — forms
- `media.html` — audio and video
- `semantic.html` — semantic tags
- `metadata.html` — page information
- `css/style.css` — styles used by all pages

## Quiz
Each page has five multiple-choice questions. The quiz uses only HTML form elements (`form`, `fieldset`, `legend`, `label`, and `input`). The answer key is inside a `details` element. There is no JavaScript, so the page does not calculate the score automatically. I can check my answers by opening “Show answers”.
