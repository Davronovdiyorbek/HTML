PAGE 9 · METADATA

Metadata and document setup

Metadata describes the document and helps browsers, search engines, and devices interpret it

<title>

Definition

Sets the document title shown in the browser tab.

Attributes

AttributeRole
—Place the title inside the head element; give each page a distinct title.

Example (code)

<head>
  <title>HTML Review Guide</title>
</head>

Example (result)

Browser preview
Browser tab title: HTML Review Guide

<meta>

Definition

Provides metadata such as character encoding, viewport settings, and description.

Attributes

AttributeRole
charsetDeclares character encoding, commonly UTF-8.
nameNames the kind of metadata.
contentProvides the metadata value.
http-equivDirective equivalent for specific cases.

Example (code)

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="A guide to HTML tags">

Example (result)

Browser preview
These settings help display characters correctly and scale pages for mobile screens.

<link, script>

Definition

Link connects external resources; script loads or contains JavaScript.

Attributes

AttributeRole
relRelationship, such as stylesheet.
hrefResource URL for link.
srcExternal script URL.
deferRuns script after document parsing.

Example (code)

<link rel="stylesheet" href="css/style.css">
<script src="app.js" defer></script>
