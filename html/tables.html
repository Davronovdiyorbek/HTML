HTML tables

Tables present information that is naturally organized into rows and columns

<table, tr, td>

Definition

A table contains rows (tr) and data cells (td).

Attributes

AttributeRole
classCSS class names.
idUnique identifier.

Example (code)

<table>
  <tr><td>HTML</td><td>Structure</td></tr>
  <tr><td>CSS</td><td>Style</td></tr>
</table>

<th, caption>

Definition

The th tag marks a header cell; caption provides a table title.

Attributes

AttributeRole
scopeIdentifies row or column header scope.
colspanSpans multiple columns.
rowspanSpans multiple rows.

Example (code)

<table>
  <caption>Study topics</caption>
  <tr><th scope="col">Topic</th><th scope="col">Goal</th></tr>
  <tr><td>HTML</td><td>Structure</td></tr>
</table>
