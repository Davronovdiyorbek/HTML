Lists in HTML

Use lists to group related items in a readable, structured way

<ul, li>

Definition

An unordered list displays items with bullets.

Attributes

AttributeRole
classCSS class names.
idUnique identifier.

Example (code)

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Example (result)

Browser preview
  • HTML
  • CSS
  • JavaScript

<ol, li>

Definition

An ordered list displays items in sequence, usually numbered.

Attributes

AttributeRole
startStarting number.
reversedNumbers in descending order.
typeNumbering style.

Example (code)

<ol start="1">
  <li>Plan</li>
  <li>Build</li>
  <li>Test</li>
</ol>

Example (result)

Browser preview
  1. Plan
  2. Build
  3. Test

<dl, dt, dd>

Definition

A description list pairs terms with descriptions.

Attributes

AttributeRole
classCSS class names.
idUnique identifier.

Example (code)

<dl>
  <dt>HTML</dt>
  <dd>Markup for web content.</dd>
</dl>
