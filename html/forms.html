HTML forms

Forms collect information through text fields, buttons, selectors, and other controls

<form>

Definition

The form element groups controls used to submit information.

Attributes

AttributeRole
actionURL that processes submitted data.
methodHTTP method, commonly get or post.
autocompleteHints whether autofill is enabled.
enctypeEncoding type, important for file uploads.

Example (code)

<form action="/submit" method="post">
  <label for="name">Name</label>
  <input id="name" name="name" required>
  <button type="submit">Send</button>
</form>

<input, label>

Definition

Input creates a control; label gives it an accessible name.

Attributes

AttributeRole
typeDefines the input control.
nameField name submitted with the form.
requiredMakes the field mandatory.
placeholderShort hint shown when empty.

Example (code)

<label for="email">Email</label>
<input id="email" name="email" type="email" required>

<select, option, textarea>

Definition

These elements let users choose an option or enter longer text.

Attributes

AttributeRole
multipleAllows more than one selection.
selectedMarks an option as selected.
rowsVisible text lines in a textarea.

Example (code)

<label for="course">Course</label>
<select id="course"><option>HTML</option><option>CSS</option></select>
