PAGE 8 · SEMANTIC HTML

Semantic and layout tags

Semantic elements describe page regions and make structure easier to understand

<header, nav, footer>

Definition

Identify introductory content, navigation, and footer information.

Attributes

AttributeRole
idUnique identifier.
classCSS class names.
aria-labelAccessible name for a region.

Example (code)

<header>Site title</header>
<nav aria-label="Main navigation">Home · About</nav>
<footer>© 2026</footer>

Example (result)

Browser preview
Site title
Home · About
© 2026

<main, section, article>

Definition

Mark main content, a thematic section, and a self-contained composition.

Attributes

AttributeRole
idUnique identifier.
classCSS class names.
aria-labelledbyAssociates a region with a heading ID.

Example (code)

<main>
  <section><h2>News</h2>
    <article>Latest update</article>
  </section>
</main>

Browser preview

News

Latest update

<div, span>

Definition

Attributes

AttributeRole
classCSS class names.
idUnique identifier.
data-*Custom data attributes.

Example (code)

<div class="card">A block with <span>inline text</span>.</div>
