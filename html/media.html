Multimedia elements

Embed sound, video, and external content while keeping controls accessible

<audio>

Definition

The audio element embeds sound the visitor can play.

Attributes

AttributeRole
controlsDisplays playback controls.
srcAudio file URL.
loopRepeats audio.
preloadHints how much media to preload.

Example (code)

<audio controls>
  <source src="images/audio-demo.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

Example (result)

Browser preview
🔊 Place an MP3 at images/audio-demo.mp3 to enable playback.

<video>

Definition

The video element embeds a video player.

Attributes

AttributeRole
controlsDisplays playback controls.
width / heightSets player dimensions.
posterImage shown before playback.
playsinlineAllows inline playback on supported devices.

Example (code)

<video controls width="360" poster="images/poster.jpg">
  <source src="images/demo.mp4" type="video/mp4">
</video>

Example (result)

Browser preview
🎥 Add images/demo.mp4 and optionally images/poster.jpg.

<iframe>

Definition

The iframe embeds another webpage or document.

Attributes

AttributeRole
srcURL of the embedded page.
titleAccessible description.
width / heightFrame dimensions.
loadingCan defer loading with lazy.

Example (code)

<iframe src="https://example.com" title="Example website" width="320" height="180"></iframe>

Example (result)

Browser preview
Use an iframe to embed an external page. Only embed sources you trust.
