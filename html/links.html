Links, images, audio & video

Connect pages and add media to make web content useful and engaging

<a>

Definition

The anchor tag creates a hyperlink to another page, file, or location.

Attributes

AttributeRole
hrefURL or page destination.
targetWhere to open the destination.
relRelationship/security hints.

Example (code)

<a href="https://example.com">Visit Example</a>

<img>

Definition

The image tag embeds an image in the page.

Attributes

AttributeRole
srcPath or URL of the image.
altText alternative for accessibility.
widthDisplay width in pixels.
heightDisplay height in pixels.

Example (code)

<img src="images/sample.jpg" alt="Mountain landscape" width="240">

<audio, video>

Definition

These elements embed playable audio and video content.

Attributes

AttributeRole
srcMedia file URL.
controlsShows playback controls.
autoplayRequests automatic playback.
mutedStarts media muted.
loopRepeats playback.

Example (code)

<video controls width="320">
  <source src="images/demo.mp4" type="video/mp4">
  Your browser does not support video.
</video>
